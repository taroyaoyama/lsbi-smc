# 構造工学の背景と問題設定

このドキュメントは、LSBI-SMC が「具体的に何を・なぜ・どのように」解こうとしているかを説明する。計算手法（SMC・MVAE）ではなく、**工学的な問題そのもの**に焦点を当てる。

---

## 1. 研究の動機：建物の「健康診断」

### 1.1 現実の建物とモデルのズレ

建物を設計・解析するとき、エンジニアは**有限要素モデル（FEモデル）**と呼ばれる数学的な模型を作る。このモデルには「各部材の剛性はいくつか」「質量はどう分布しているか」といった**物理パラメータ**を設定する必要がある。

しかし現実の建物では：

- 材料（コンクリート・鋼材）の強度は製造ロットによってバラつく
- 施工の誤差が生じる
- 竣工後の経年劣化・地震による損傷でパラメータが変化する
- 接合部の挙動は設計段階の仮定通りにならない

結果として、**「設計値として入力したパラメータ」と「実際の建物が持つパラメータ」は一致しない**。

```
設計モデル: k₁ = k₂ = k₃ = k₄ = 1000 N/m（全階同じ剛性を仮定）
　↓　竣工・経年・損傷
実際の建物: k₁ = 950, k₂ = 1100, k₃ = 870, k₄ = 1050 N/m（各階でバラバラ）
```

### 1.2 FEモデル更新（Model Updating）とは

「観測データを使って、モデルのパラメータを実際の建物に合わせ込む」操作を**FEモデル更新**という。

目的は2つある：

1. **現状把握：** 現在の建物が設計通りの性能を持っているか確認する（構造ヘルスモニタリング）
2. **損傷検知：** 地震や経年劣化で剛性が低下した箇所を特定する

> **一言で言うと：** 振動を測定して、建物の「見えない内部状態」を推定する問題。

### 1.3 なぜ地震時の振動データを使うか

建物に加振機を取り付けて人工的に振動させることもできるが、大型建物では現実的でない。

一方、**地震は否応なく建物を揺らす**。その応答を計測すれば、コストゼロで「入力（地面の揺れ）→ 出力（建物の揺れ）」のデータが得られる。このデータから建物の特性を逆算するのが本研究のゴールである。

## 2. 対象：4層せん断建物モデル

### 2.1 物理的なモデル

本研究が対象とするのは**4層（4階建て）のせん断建物**を数学的に単純化したモデルである。

```
　　屋根（4階） ○──── センサー（FRFを観測）
　　　　　　　　│  k₄（4層の剛性）
　　　3階　　　 ○
　　　　　　　　│  k₃
　　　2階　　　 ○
　　　　　　　　│  k₂
　　　1階　　　 ○
　　　　　　　　│  k₁
　　　地盤　　　▒▒▒▒▒▒▒▒　← 地震入力（基部加速度）
```

**せん断建物モデルの仮定：**

- 各階の床（スラブ）は水平方向にしか動かない（回転変形を無視）
- 各階の質量は床に集中している（柱・壁の質量は無視）
- 水平変形は各階の「ばね（剛性 $k_i$）」で表現する

この単純化により、4階建て建物の水平振動を「4個のばねと4個のおもり」の系として扱える（**4自由度系、4DOF**）。

### 2.2 推定したいパラメータ

$$\theta = (k_1, k_2, k_3, k_4)$$

各 $k_i$ は「その階の水平剛性（横揺れに対するバネの固さ）」を表す。単位は N/m。

**実装では無次元化して扱う：**

$$k_i = \theta_i \times k_0, \qquad k_0 = 1000 \text{ N/m}$$

例えば $\theta_i = 1.0$ なら設計値通り、$\theta_i = 0.5$ なら設計値の半分（損傷している可能性）。

**パラメータの探索範囲：**

$$\theta_i \in [0.33, 3.00] \quad \text{（設計値の1/3 〜 3倍）}$$

```python
LLIM, ULIM = 0.33, 3.00  # create_dataset.py
```

## 3. 順問題：シミュレーター（FRF計算）

### 3.1 「順問題」とは

| 問題の方向 | 入力 | 出力 |
|-----------|------|------|
| **順問題** | パラメータ $\theta$（剛性） | 観測量（FRF） |
| **逆問題** | 観測量（FRF） | パラメータ $\theta$（剛性） |

順問題は「設計図があれば、どう揺れるかを計算できる」。逆問題は「揺れ方を観測して、設計図を推定する」。本研究の目標は逆問題だが、逆問題を解くには順問題（シミュレーター）が必須。

### 3.2 運動方程式

4自由度系の振動を支配する方程式（**運動方程式**）：

$$M\ddot{\mathbf{u}}(t) + C\dot{\mathbf{u}}(t) + K\mathbf{u}(t) = -M\mathbf{1}\,\ddot{u}_g(t)$$

| 記号 | 意味 | サイズ |
|------|------|--------|
| $\mathbf{u}(t)$ | 各階の水平変位（時刻 $t$） | 4×1 ベクトル |
| $\dot{\mathbf{u}}, \ddot{\mathbf{u}}$ | 速度・加速度 | 4×1 |
| $M$ | 質量行列（各階の質量） | 4×4 対角行列 |
| $C$ | 減衰行列（エネルギー散逸） | 4×4 行列 |
| $K$ | 剛性行列（バネの固さ） | 4×4 行列 |
| $\ddot{u}_g(t)$ | 地震による地盤加速度（入力） | スカラー |
| $\mathbf{1}$ | 全要素が1のベクトル（全階に同じ入力） | 4×1 |

右辺の $-M\mathbf{1}\,\ddot{u}_g(t)$ が「地震による強制力」。地盤が揺れると、それに乗っている各階の質量に慣性力が働く。

### 3.3 剛性行列の構造

4層建物の剛性行列はパラメータ $(k_1, k_2, k_3, k_4)$ から直接組み立てられる：

$$K = \begin{pmatrix}
k_1 + k_2 & -k_2 & 0 & 0 \\
-k_2 & k_2 + k_3 & -k_3 & 0 \\
0 & -k_3 & k_3 + k_4 & -k_4 \\
0 & 0 & -k_4 & k_4
\end{pmatrix}$$

**直感的な読み方：**

- 対角成分 $(i, i)$：$i$ 階の「上下のバネの合計」が自分自身の変位に抵抗する
- 非対角成分 $(i, i+1)$：隣の階との「相対変形」による反力（引っ張り合い）

```python
# frfshearm.py
k_mat = np.zeros((n_dof, n_dof))
k_mat[0, 0] += ks[0]
for i in range(1, n_dof):
    k_mat[(i-1):(i+1), (i-1):(i+1)] += np.array([[ks[i], -ks[i]], [-ks[i], ks[i]]])
```

### 3.4 固有値解析（モーダル解析）

#### 3.4.1 一般化固有値問題としての定式化

運動方程式から減衰と外力を取り除いた **無減衰自由振動** を考える：

$$M\ddot{\mathbf{u}} + K\mathbf{u} = 0$$

調和振動 $\mathbf{u}(t) = \boldsymbol{\phi}\sin(\omega t)$ を仮定して代入すると、$\sin$ が両辺で消え：

$$K\boldsymbol{\phi} = \omega^2 M\boldsymbol{\phi}$$

これは**一般化固有値問題** $A\mathbf{v} = \lambda B\mathbf{v}$ の形（$A=K$, $B=M$, $\lambda = \omega^2$）。線形代数の基礎は [01_linear_algebra.md §4](01_linear_algebra.md) を参照。

4DOF 系では4組の解 $(\omega_r^2, \boldsymbol{\phi}_r),\ r=1,\ldots,4$ が得られる：

- $\omega_r$：$r$ 次の **固有角振動数**（建物が「自然に揺れたがる周波数」）
- $\boldsymbol{\phi}_r$：$r$ 次の **モード形状**（各階がどの割合で動くか）

第1モードが最もゆっくり揺れる基本振動（1〜数Hz）、第4モードが最も速い振動に対応する。

> **形に注意：$\omega^2$ はスカラー、$\Lambda$ は対角行列**
>
> $\omega_1, \omega_2, \omega_3, \omega_4$ と複数あるので $\omega^2$ も「ベクトル」と思いたくなるが、$K\boldsymbol{\phi} = \omega^2 M\boldsymbol{\phi}$ の $\omega^2$ は **1モード分のスカラー**である。ベクトルだとすると $\omega^2 \cdot M\boldsymbol{\phi}$ の積が「ベクトル × 行列 × ベクトル」となり次元が合わない。
>
> 全モードを一つの式にまとめたいときは、**ベクトルではなく対角行列**を使って次のように書く：
>
> $$K\Phi = M\Phi\Lambda, \qquad \Phi = [\boldsymbol{\phi}_1, \boldsymbol{\phi}_2, \boldsymbol{\phi}_3, \boldsymbol{\phi}_4],\quad \Lambda = \mathrm{diag}(\omega_1^2, \omega_2^2, \omega_3^2, \omega_4^2)$$
>
> 行列 $\Phi$ の右から $\Lambda$ を掛けると「列 $r$ にだけ $\omega_r^2$ が掛かる」ので、列ごとに見れば元の4本の式 $K\boldsymbol{\phi}_r = \omega_r^2 M\boldsymbol{\phi}_r$ に分解される。
>
> 実装の `lam` は形状 `(4,)` のベクトルとして返ってくるが、これは対角行列 $\Lambda$ を**対角成分だけのコンパクト表現**で持っているもの。本来の数学的役割は対角行列である点に注意（実際にモード減衰計算 [frfshearm.py:72](../src/lsbi_smc/example_shear4dof/frfshearm.py#L72) ではブロードキャストで「列ごとに $\omega_r$ を掛ける」操作になっている）。

#### 3.4.2 コードとの対応

```python
# frfshearm.py:39-40
lam, phi = eigh(k_mat, m_mat)       # 一般化固有値問題（A=K, B=M）
omega_nat = np.sqrt(lam)             # 固有角振動数 [rad/s]
```

`scipy.linalg.eigh` は対称正定値行列ペアに最適化されたソルバーで、内部的には Cholesky 分解 $M = LL^T$ を使って標準形に変換してから解いている（[01_linear_algebra.md §4.4](01_linear_algebra.md) 参照）。`np.linalg.eig` よりも高速かつ数値的に安定。

**戻り値の構造：**

| 変数 | 形状 | 意味 |
|------|------|------|
| `lam` | `(4,)` | $\omega_r^2$ を昇順に並べたベクトル |
| `phi` | `(4, 4)` | 固有ベクトルを **列方向に並べた** 行列。`phi[:, r]` が $r$ 次モード |

#### 3.4.3 モード直交性（後の議論の伏線）

対称行列ペアの一般化固有ベクトルには次の重要な性質がある（**M-直交性、K-直交性**）：

$$\Phi^T M \Phi = I, \qquad \Phi^T K \Phi = \mathrm{diag}(\omega_1^2, \omega_2^2, \omega_3^2, \omega_4^2)$$

つまり「$\Phi$ で座標変換すると、**$M$ と $K$ が同時に対角化される**」。この性質が次節のレイリー減衰と、§4.2 の FRF 計算の数学的基盤になる。

### 3.5 レイリー減衰

#### 3.5.1 動機：減衰行列をどう与えるか

実際の建物は揺れると徐々にエネルギーが散逸して止まる（**減衰**）。しかし「減衰行列 $C$ の各要素」を物理から直接決めるのは難しい。建物の振動エネルギーが摩擦・空気抵抗・微視的な材料散逸など多様な機構で失われるためである。

そこで実用上、**「モードごとの減衰比」を指定する形** に問題を帰着させたい。「1次モードは2%、2次モードは2%」のように指定するほうが、エンジニアの直感とも一致する。

#### 3.5.2 レイリー減衰の仮定

$C$ を質量と剛性の線形結合として与える：

$$C = a_0 M + a_1 K$$

これ自体に物理的根拠はなく、**数学的な扱いやすさのための仮定**。利点は次に出てくる。

#### 3.5.3 モード分解で対角化される

§3.4.3 のモード直交性 $\Phi^T M \Phi = I$, $\Phi^T K \Phi = \mathrm{diag}(\omega_r^2)$ を $C$ に適用すると：

$$\Phi^T C \Phi = a_0 \Phi^T M \Phi + a_1 \Phi^T K \Phi = a_0 I + a_1 \mathrm{diag}(\omega_r^2)$$

つまり $C$ も**同じ $\Phi$ で対角化される**（これを **古典減衰** という）。$r$ 次モードの対角成分は $a_0 + a_1\omega_r^2$。

**これがレイリー減衰の本質：** モード分解後の方程式が完全に分離され、各モードを独立な1自由度系として解析できる。

#### 3.5.4 モード減衰比の式（ω が登場する理由）

1自由度系の運動方程式 $m\ddot{u} + c\dot{u} + ku = 0$ で、減衰比 $\zeta$ は **臨界減衰 $2\sqrt{km} = 2\omega m$ に対する比** として定義される：

$$c = 2\zeta \omega m \quad\Longleftrightarrow\quad \zeta = \frac{c}{2\omega m}$$

$r$ 次モードでは「モード質量=1（M-直交化済み）」「モード減衰=$a_0 + a_1\omega_r^2$」「モード固有振動数=$\omega_r$」なので：

$$\zeta_r = \frac{a_0 + a_1\omega_r^2}{2\omega_r} = \frac{a_0}{2\omega_r} + \frac{a_1 \omega_r}{2}$$

ここで $\omega_r$ が出てくるのは「$M$ と $K$ が $\omega_r$ で表せるから」ではなく、**減衰比の定義 $\zeta = c/(2\omega m)$ そのものに $\omega$ が含まれているから**である。

> **補足：なぜ $c = 2\zeta\omega m$ なのか（臨界減衰の導出）**
>
> $c = 2\zeta\omega m$ は天下り的な定義に見えるが、半分は物理から導かれ、半分は無次元化のための定義である。
>
> **(1) 特性方程式から臨界減衰が現れる**
>
> 1自由度系 $m\ddot{u} + c\dot{u} + ku = 0$ に $u = e^{\lambda t}$ を代入すると特性方程式が得られる：
>
> $$m\lambda^2 + c\lambda + k = 0 \quad\Longrightarrow\quad \lambda = \frac{-c \pm \sqrt{c^2 - 4mk}}{2m}$$
>
> 解の挙動は **判別式 $c^2 - 4mk$ の符号** で3パターンに分かれる：
>
> | 判別式 | $\lambda$ | 物理的な挙動 |
> |--------|-----------|-------------|
> | $c^2 < 4mk$ | 複素共役解 | **振動しながら減衰**（不足減衰、underdamped） |
> | $c^2 = 4mk$ | 実重根 | **振動せず最短時間で停止**（臨界減衰、critical） |
> | $c^2 > 4mk$ | 実2根 | **振動せず緩やかに減衰**（過減衰、overdamped） |
>
> 「振動するかしないか」の境界に当たる $c$ の値は物理的に特別で、これを **臨界減衰係数** と呼ぶ：
>
> $$c_{\text{cr}} = 2\sqrt{km}$$
>
> **(2) ω で書き直す**
>
> 固有角振動数の定義 $\omega = \sqrt{k/m}$ より $\sqrt{km} = m\sqrt{k/m} = m\omega$ なので：
>
> $$c_{\text{cr}} = 2\sqrt{km} = 2\omega m$$
>
> **(3) 減衰比 ζ は「臨界減衰の何倍か」**
>
> 減衰比 $\zeta$ は実際の減衰係数 $c$ を臨界減衰で割った無次元量として定義される：
>
> $$\zeta \;\equiv\; \frac{c}{c_{\text{cr}}} = \frac{c}{2\omega m}$$
>
> これを $c$ について解いたのが $c = 2\zeta\omega m$ である。
>
> **(4) なぜ ζ で表すと便利か**
>
> $c$ の値そのものは構造形式・規模で桁が大きく変わるが、$\zeta$ は「臨界減衰の何%か」というスケール不変の量で、構造形式ごとに大体のオーダーが決まっている：
>
> | 構造形式 | 典型的な $\zeta$ |
> |---------|----------------|
> | 鋼構造 | 1〜2% |
> | RC構造 | 3〜5% |
> | 免震構造 | 10〜30% |
>
> このため設計実務でも「$c$ をいくつにしますか」ではなく「$\zeta$ をいくつにしますか」で議論する。レイリー減衰がモード減衰比 $\zeta_r$ を指定する形に帰着するのも、この実務的便利さに合わせた定式化である。

#### 3.5.5 $a_0, a_1$ の決定（連立方程式）

$\zeta_r = \zeta$ となる $r$ は2つしか指定できない（未知数が $a_0, a_1$ の2つだから）。本実装では **1Hz と 20Hz で減衰比 2%** を指定する：

$$\begin{pmatrix} \zeta_1 \\ \zeta_2 \end{pmatrix} = \underbrace{\begin{pmatrix} \frac{1}{2\omega_1} & \frac{\omega_1}{2} \\ \frac{1}{2\omega_2} & \frac{\omega_2}{2} \end{pmatrix}}_{\text{coefficient matrix}} \begin{pmatrix} a_0 \\ a_1 \end{pmatrix}$$

これを $a_0, a_1$ について解く（[01_linear_algebra.md §2.3](01_linear_algebra.md) 参照）。

```python
# frfshearm.py:62-66
a_coeff = np.array(
    [[1 / (2 * omega1), omega1 / 2],
     [1 / (2 * omega2), omega2 / 2]], dtype=float
)
b = np.array([zeta1, zeta2], dtype=float)
a0, a1 = np.linalg.solve(a_coeff, b)
```

ターゲット周波数の設定は呼び出し側で行う：

```python
# create_dataset.py / inference.py
omega_target = np.array([1.0, 20.0]) * 2 * np.pi  # 1Hz と 20Hz
zeta = 0.02                                          # 減衰比 2%
```

#### 3.5.6 レイリー減衰の周波数特性（U字曲線）

決まった $a_0, a_1$ から、任意のモードの減衰比は：

$$\zeta_r = \underbrace{\frac{a_0}{2\omega_r}}_{\text{低周波で支配的}} + \underbrace{\frac{a_1 \omega_r}{2}}_{\text{高周波で支配的}}$$

縦軸 $\zeta$、横軸 $\omega$ で描くと **U字曲線** になる：指定した2点（$\omega_1, \omega_2$）の間では減衰比が小さく、外側では大きくなる。

```
ζ
 │ ＼      ／
 │  ＼   ／
 │   ＼／← ω₁ と ω₂ の間で最小
 │  ω₁  ω₂                        → ω
```

**実装の対応関係：**

```python
# frfshearm.py:72
zeta_r = a0 / (2 * omega_nat) + a1 * omega_nat / 2
```

`omega_nat` は §3.4 で求めた固有角振動数のベクトル `(n_dof,)` で、ブロードキャスティング（[01_linear_algebra.md §3](01_linear_algebra.md)）により全モードの $\zeta_r$ が一括計算される。

## 4. 観測量：周波数応答関数（FRF）

### 4.1 FRFとは何か

**FRF（Frequency Response Function）**とは「ある周波数の地震入力に対して、建物がどれだけ・どのように応答するか」を周波数ごとに表した関数。

$$H_i(\omega) = \frac{\text{$i$ 階の加速度応答}}{\text{地盤の加速度入力}}$$

FRFを見ることで、どの周波数帯域で建物が大きく揺れるか（**共振**）が一目でわかる。

### 4.2 FRFの計算式（モード重ね合わせ法）

#### 4.2.1 数学的導出のあらまし

§3.4.3 のモード直交性により、運動方程式は **モード座標 $\mathbf{q}(t) = \Phi^{-1}\mathbf{u}(t)$** に変換すると完全に分離する。以下、§3.2 の運動方程式から各モードの 1 自由度形式まで 4 ステップで導く。

##### 出発点（§3.2）

$$M\ddot{\mathbf{u}}(t) + C\dot{\mathbf{u}}(t) + K\mathbf{u}(t) = -M\mathbf{1}\,\ddot{u}_g(t) \qquad (\star)$$

$\mathbf{u}\in\mathbb{R}^4$ は物理座標（各階の変位）。

##### ステップ1：モード座標への変数変換

モード行列 $\Phi = [\boldsymbol{\phi}_1,\ldots,\boldsymbol{\phi}_4]$ を用いて新しい変数 $\mathbf{q}(t)$ を導入：

$$\mathbf{u}(t) = \Phi\,\mathbf{q}(t) \qquad (\text{逆に書けば } \mathbf{q} = \Phi^{-1}\mathbf{u})$$

$\Phi$ は時間に依存しない定数行列なので時間微分が素直に通り、$\dot{\mathbf{u}} = \Phi\dot{\mathbf{q}}$, $\ddot{\mathbf{u}} = \Phi\ddot{\mathbf{q}}$。これを $(\star)$ に代入：

$$M\Phi\ddot{\mathbf{q}} + C\Phi\dot{\mathbf{q}} + K\Phi\mathbf{q} = -M\mathbf{1}\,\ddot{u}_g(t)$$

この時点ではまだ各成分が結合していて、何も嬉しくない。

##### ステップ2：左から $\Phi^T$ を掛ける

$$\Phi^T M\Phi\,\ddot{\mathbf{q}} + \Phi^T C\Phi\,\dot{\mathbf{q}} + \Phi^T K\Phi\,\mathbf{q} = -\Phi^T M\mathbf{1}\,\ddot{u}_g(t) \qquad (\star\star)$$

なぜ左から $\Phi^T$ か：3つの行列ペア $\Phi^T M\Phi$, $\Phi^T C\Phi$, $\Phi^T K\Phi$ が次ステップで**同時に対角化**されるから。

##### ステップ3：3つの直交性で対角化

§3.4.3・§3.5.3・§3.5.4 の結果をそのまま使う：

| 項 | 値 | 由来 |
|----|----|----|
| $\Phi^T M\Phi$ | $I$ | M-直交性（§3.4.3） |
| $\Phi^T K\Phi$ | $\mathrm{diag}(\omega_r^2)$ | K-直交性（§3.4.3） |
| $\Phi^T C\Phi$ | $\mathrm{diag}(a_0 + a_1\omega_r^2) = \mathrm{diag}(2\zeta_r\omega_r)$ | レイリー減衰 + §3.5.4 の $a_0 + a_1\omega_r^2 = 2\zeta_r\omega_r$ |

これらを $(\star\star)$ に入れると左辺の行列はすべて対角になる：

$$\ddot{\mathbf{q}} + \mathrm{diag}(2\zeta_r\omega_r)\,\dot{\mathbf{q}} + \mathrm{diag}(\omega_r^2)\,\mathbf{q} = -\Phi^T M\mathbf{1}\,\ddot{u}_g(t)$$

##### ステップ4：励起係数を定義して成分ごとに書き下す

右辺のベクトル $\Phi^T M\mathbf{1}$ の第 $r$ 成分を **励起係数**

$$g_r \;\equiv\; \boldsymbol{\phi}_r^T M\mathbf{1}$$

と置く。左辺は対角なので各行は $r$ 番目の成分しか含まず、行 $r$ を抜き出すと

$$\ddot{q}_r + 2\zeta_r\omega_r\,\dot{q}_r + \omega_r^2 q_r = -g_r\,\ddot{u}_g(t), \qquad r=1,\ldots,4$$

**4 自由度の連立系が、互いに独立な4つの1自由度系に完全分離した**。これがモード重ね合わせ法の核心。

##### ステップ5：周波数領域で解く

ステップ4 で得た方程式

$$\ddot{q}_r + 2\zeta_r\omega_r\,\dot{q}_r + \omega_r^2 q_r = -g_r\,\ddot{u}_g(t)$$

は **時間 $t$ の関数についての微分方程式**。これを **周波数 $\omega$ の関数についての代数方程式（割り算で解ける式）** に変換するのが **フーリエ変換** の役割。

フーリエ変換の定義と「微分が掛け算 $j\omega$ に化ける」性質、および2階線形定数係数 ODE への適用パターンは [01_linear_algebra.md §5](01_linear_algebra.md) にまとめてある。鍵となる対応関係だけ再掲：

| 時間領域 | 周波数領域 |
|----|----|
| $f(t)$ | $\hat{f}(\omega)$ |
| $\dot{f}(t)$ | $j\omega\,\hat{f}(\omega)$ |
| $\ddot{f}(t)$ | $-\omega^2\,\hat{f}(\omega)$ |

以下、3つの小ステップに分けて FRF まで持っていく。

###### 5-1. モード方程式に適用する

ステップ4 のモード方程式の両辺をフーリエ変換する。$q_r(t) \to \hat{q}_r(\omega)$, $\ddot{u}_g(t) \to \hat{\ddot{u}}_g(\omega)$ と書き、上の対応関係を代入すると：

$$-\omega^2\hat{q}_r + 2\zeta_r\omega_r\,(j\omega)\,\hat{q}_r + \omega_r^2\,\hat{q}_r = -g_r\,\hat{\ddot{u}}_g(\omega)$$

$\hat{q}_r$ について整理：

$$\bigl(\omega_r^2 - \omega^2 + 2j\zeta_r\omega_r\omega\bigr)\,\hat{q}_r = -g_r\,\hat{\ddot{u}}_g$$

両辺を括弧の中身で割れば、**$\hat{q}_r$ が陽に求まる**：

$$\hat{q}_r(\omega) = \frac{-g_r}{\omega_r^2 - \omega^2 + 2j\zeta_r\omega_r\omega}\,\hat{\ddot{u}}_g(\omega) \qquad (\dagger)$$

> **共振がここに現れる：** 分母 $\omega_r^2 - \omega^2 + 2j\zeta_r\omega_r\omega$ は $\omega = \omega_r$ で実部が $0$ になり、虚部の $2j\zeta_r\omega_r^2$ だけが残る。$\zeta_r$ は小さい（数%）ので分母の絶対値も小さくなり、$\hat{q}_r$ が大きく増幅される。これが「共振」の数式的正体。

###### 5-2. 物理座標に戻して加速度の比をとる

$(\dagger)$ はモード座標 $\hat{q}_r$ についての式なので、$\mathbf{u} = \Phi\mathbf{q}$ で物理座標に戻す。$i$ 階の変位の周波数成分は

$$\hat{u}_i(\omega) = \sum_{r=1}^{4} \Phi_{ir}\,\hat{q}_r(\omega)$$

$i$ 階の **相対加速度**（地盤に対する加速度）は対応表の規則で $\hat{\ddot{u}}_i = -\omega^2\,\hat{u}_i$、**絶対加速度**（地面ごと一緒に動く成分も含む）は

$$\ddot{u}_i^{\text{abs}} = \ddot{u}_i + \ddot{u}_g \quad\Longrightarrow\quad \hat{\ddot{u}}_i^{\text{abs}} = -\omega^2\,\hat{u}_i + \hat{\ddot{u}}_g$$

FRF の定義（§4.1）は「絶対加速度 ÷ 地盤加速度」なので

$$H_i(\omega) = \frac{\hat{\ddot{u}}_i^{\text{abs}}}{\hat{\ddot{u}}_g} = 1 + \frac{-\omega^2\,\hat{u}_i}{\hat{\ddot{u}}_g}$$

最初の $1$ は地盤入力がそのまま乗っかっている分（建物が剛体なら $H_i \equiv 1$）。

###### 5-3. $(\dagger)$ を代入してまとめる

$\hat{u}_i = \sum_r \Phi_{ir}\hat{q}_r$ と $(\dagger)$ を上の式に入れる：

$$\frac{-\omega^2\,\hat{u}_i}{\hat{\ddot{u}}_g} = -\omega^2 \sum_{r=1}^{4}\Phi_{ir}\,\frac{\hat{q}_r}{\hat{\ddot{u}}_g} = -\omega^2 \sum_{r=1}^{4}\Phi_{ir}\,\frac{-g_r}{\omega_r^2 - \omega^2 + 2j\zeta_r\omega_r\omega}$$

マイナス符号が2つ重なって消え、$\hat{\ddot{u}}_g$ も約分されて、結局 $\omega$ だけの式になる：

$$\boxed{\;H_i(\omega) = 1 + \omega^2 \sum_{r=1}^{4} \frac{\Phi_{ir}\, g_r}{\omega_r^2 - \omega^2 + 2j\zeta_r \omega_r \omega}\;}$$

各項の出どころ：

- **先頭の $1$** ← 5-2 の絶対加速度の式の $\hat{\ddot{u}}_g/\hat{\ddot{u}}_g$
- **$\omega^2$** ← 変位 → 加速度の二階微分（$\ddot{f} \to -\omega^2 \hat{f}$）
- **$\Phi_{ir}$** ← モード座標 → 物理座標の戻し（5-2）
- **$g_r$** ← 地震がそのモードをどれだけ励起するか（ステップ4）
- **分母** ← 1自由度系の応答関数（5-1）

**入力 $\hat{\ddot{u}}_g$ が約分で消えるのが重要：** $H_i(\omega)$ は地震波形に依存せず、**建物だけで決まる量**になる。「どんな地震が来てもこの周波数では○倍に増幅される」という建物固有の性質。

| 記号 | 意味 |
|------|------|
| $\omega$ | 入力の角振動数（計算したい周波数） |
| $\Phi_{ir}$ | $r$ 次モードの $i$ 階での振動振幅 |
| $g_r = \boldsymbol{\phi}_r^T M \mathbf{1}$ | $r$ 次モードの励起係数（地震がどれだけそのモードを揺らすか） |
| 分母 | $\omega$ が $\omega_r$ に近づくと小さくなり → 共振で大きく増幅 |

#### 4.2.2 コードとの対応

```python
# frfshearm.py:75-86
r = np.ones(n_dof)                          # 影響ベクトル
m_r = m_mat @ r                              # M·1
g = phi.T @ m_r                              # g_r = φ_r^T M·1（全モード）
omeg = (np.arange(dlf, fmax + dlf, dlf) * 2 * np.pi).astype(float)

omega_nat_col = omega_nat[:, None]           # (n_dof, 1)
zeta_r_col = zeta_r[:, None]                 # (n_dof, 1)
denom = (
    -(omeg[None, :] ** 2)                   # (1, n_freq)
    + 2j * zeta_r_col * omega_nat_col * omeg[None, :]
    + omega_nat_col**2
)
v = (1.0 / denom) * g[:, None]              # モーダル応答 (n_dof, n_freq)
u_mat = phi @ v                              # 全階の変位 (n_dof, n_freq)
h_frf = r[:, None] + (omeg[None, :] ** 2) * u_mat   # 加速度FRF
```

ここでブロードキャスティング（[01_linear_algebra.md §3](01_linear_algebra.md)）が活躍している：

- `omega_nat[:, None]` で「モード方向の軸」を作る
- `omeg[None, :]` で「周波数方向の軸」を作る
- これらを掛け合わせると `(n_dof, n_freq)` の行列ができ、**全モード × 全周波数の応答が一気に計算される**

明示的な for ループより数十倍速い。これが NumPy らしい高速化パターン。

### 4.3 なぜ対数スケールで扱うか

FRFの振幅は共振ピーク付近で数桁（例：0.001 〜 100）もの大きな変化がある。この「桁が変わる量」を機械学習に直接入力するのは扱いにくい。

対数を取ることで：
- 桁の変化がなだらかな変化になる
- 共振ピークの「幅の広さや形」が見やすくなる

$$x_n = \log|H_i(\omega_n)|, \quad n = 1, 2, \ldots, 1024$$

```python
return np.log(np.abs(h_frf))  # frfshearm.py の最終出力
```

### 4.4 どのデータを観測するか（屋根センサー）

4層建物には4階分のFRFがあるが、本研究では**屋根（最上階）のFRFのみ**を観測量として使う：

```python
# inference.py
y_obs = simulator(x_obs)[:, [-1], :, :]  # チャンネル[-1] = 屋根（4階）のみ
```

```python
# train.py
y = y[:, [-1], :, :]   # 訓練でも屋根チャンネルのみを使う
```

これは「屋根に1個だけセンサーを置く」という**現実的なシナリオ**を模擬している。センサーは少ないほど実用的だが、情報量が減るため推定が難しくなる（後述）。

### 4.5 観測ノイズ

現実のセンサー計測にはノイズが乗る。本実装ではガウスノイズを加える：

$$x_{\text{noisy}} = \log|H(\omega)| + \epsilon, \qquad \epsilon \sim \mathcal{N}(0, \sigma_{\text{noise}}^2)$$

```python
noise_level = 0.20
y_sim_n = y_sim + noise_level * norm.rvs(size=y_sim.shape)  # create_dataset.py
```

```python
# inference.py（推論時の観測値生成）
y_obs = y_obs + norm.rvs(size=y_obs.shape, random_state=101) * 0.20
```

ノイズ標準偏差 0.20 は、FRFの対数値（通常 −5 〜 5 程度の範囲）に対して**約4%**のノイズに相当する。

## 5. 逆問題：剛性パラメータの推定

### 5.1 問題の定式化

**入力（観測）：** 屋根のFRF $\mathbf{x}_{\text{obs}} \in \mathbb{R}^{1024}$（1024周波数点の振幅値）

**出力（推定したいもの）：** 剛性パラメータ $\theta = (\theta_1, \theta_2, \theta_3, \theta_4)$

**シミュレーター（順問題）：** $h: \theta \mapsto \mathbf{x}$

```
FRFシミュレーター h(θ)
  θ = (k₁, k₂, k₃, k₄) → frfshearm2() → x ∈ ℝ¹⁰²⁴
```

ベイズ推論の枠組みでは「観測した FRF を説明するパラメータの分布（事後分布）」を求める：

$$p(\theta \mid \mathbf{x}_{\text{obs}}) \propto p(\mathbf{x}_{\text{obs}} \mid \theta) \cdot p(\theta)$$

- **尤度 $p(\mathbf{x}_{\text{obs}} \mid \theta)$：** パラメータ $\theta$ のときに観測 $\mathbf{x}_{\text{obs}}$ が得られる確率
- **事前分布 $p(\theta)$：** 観測前の「$\theta$ がとりうる範囲への信念」

### 5.2 なぜベイズ推論か（点推定との違い）

最もシンプルな逆問題の解法は**点推定**：「$\mathbf{x}_{\text{obs}}$ に最も近い FRF を与える $\theta$ を一つ見つける」。しかしこれには問題がある。

**ベイズ推論（確率分布として推定）の利点：**

| 特徴 | 点推定 | ベイズ推論 |
|------|-------|----------|
| 出力 | 一つの値 $\hat{\theta}$ | 分布 $p(\theta \mid x_{\text{obs}})$ |
| 不確実性 | 表現できない | 「信頼の幅」を表現できる |
| 多峰性 | 一つの山しか見つからない | 複数の解候補を同時に表現できる |

特に本問題では**多峰性**（後述）が深刻なため、ベイズ推論が必須となる。

### 5.3 等価解の問題（多峰性）：なぜ一つに決まらないか

屋根のFRFだけを観測する場合、**異なる剛性の組み合わせが同じ屋根 FRF を与える**ことがある。

| 解 | $\theta_1$ | $\theta_2$ | $\theta_3$ | $\theta_4$ | 屋根FRF |
|----|-----------|-----------|-----------|-----------|---------|
| 真値 | 1.000 | 1.000 | 1.000 | 1.000 | 同じ |
| 等価解A | 1.722 | 0.636 | 1.301 | 0.701 | 同じ |
| 等価解B | 1.999 | 1.000 | 0.500 | 1.000 | 同じ |
| 等価解C | 2.640 | 0.647 | 0.813 | 0.720 | 同じ |

これは「屋根1点だけを見ているので、各階の個別の情報が失われている」ことに起因する。4本の弦を別々に調整しても、全体の和音（屋根の応答）が同じになる場合があるイメージ。

**結果として事後分布は「多峰性」になる：**

```
p(θ₁, θ₂ | x_obs)の断面

確率密度
　↑
　│  ★（真値）      ★（等価解A）
　│
　│             ★（等価解B）   ★（等価解C）
　│
　└──────────────────────────────→ θ₁
```

通常のMCMC（NUTSなど）は一つの山を登ることしかできず、他の峰を見逃す。**SMC（逐次モンテカルロ）はテンパリングによってこの多峰性を扱える**（詳細は [02_probability.md §8](02_probability.md) 参照）。

### 5.4 直接計算の壁：なぜ尤度計算が難しいか

素朴な尤度の計算：

$$p(\mathbf{x}_{\text{obs}} \mid \theta) = \mathcal{N}(\mathbf{x}_{\text{obs}} \mid h(\theta), \sigma_{\text{noise}}^2 I)$$

「$\theta$ のFRF計算結果 $h(\theta)$ と観測 $\mathbf{x}_{\text{obs}}$ の差」を計算すればよい……に見えるが、2つの問題がある：

1. **高次元空間での距離：** $\mathbf{x}_{\text{obs}}$ は 1024次元のベクトル。1024次元空間での「近さ」は単純なユークリッド距離では意味をなさなくなる（次元の呪い）
2. **計算コスト：** SMCでは数千〜数万の粒子に対して毎ステップ尤度を計算する必要がある。1回のFRF計算は有限要素解析を含むため重い

**解決策：潜在空間での尤度計算**

本研究の核心的なアイデアは「1024次元の高次元FRF空間」ではなく「8次元の潜在空間（$z$ 空間）」で尤度を計算すること。これが MVAE と SMC を組み合わせる理由（詳細は [06_latent_likelihood.md](06_latent_likelihood.md) 参照）。

## 6. データセット：何を・どう準備するか

### 6.1 データセットの役割

本研究の手法は「**学習（オフライン）**」と「**推論（オンライン）**」の2フェーズに分かれる：

- **学習フェーズ（オフライン）：** 大量のシミュレーションデータを使って MVAE を訓練する
- **推論フェーズ（オンライン）：** 訓練済み MVAE を使って、新しい観測 $\mathbf{x}_{\text{obs}}$ からパラメータを推定する

学習フェーズで作るデータセットが `train_data.npz`。

### 6.2 データセットの作り方

```
Step 1: パラメータをラテン超方格法でサンプリング（n=100,000組）
Step 2: 各パラメータについてFRFをシミュレーション
Step 3: ノイズを加えて「ノイズあり」バージョンも作成
Step 4: npzファイルに保存
```

**ラテン超方格法（Latin Hypercube Sampling）とは：**

4次元パラメータ空間を効率よくサンプリングする方法。単純なランダムサンプリングと比べて「空間全体を均等にカバー」できる。

```python
# create_dataset.py
sampler = qmc.LatinHypercube(d=4)   # 4次元（k₁〜k₄）
x_sim = sampler.random(n_sim)        # 100,000組を [0,1]^4 でサンプリング
```

ここでサンプリングされる `x_sim` は **正規化済みパラメータ**（$[0, 1]^4$ の範囲）。Simulator クラスが実際の計算時に物理値 $[0.33, 3.00]$ へスケール変換する：

```python
# simulator.py
theta = theta * (ULIM - LLIM) + LLIM  # [0,1] → [0.33, 3.00]
```

### 6.3 データセットの構造

```python
np.savez("train_data.npz",
    llim = 0.33,            # パラメータの下限
    ulim = 3.00,            # パラメータの上限
    x_sim = ...,            # 正規化パラメータ (100000, 4)
    y_sim = ...,            # クリーンなFRF     (100000, 4, 1, 1024)
    y_sim_n = ...,          # ノイズありFRF    (100000, 4, 1, 1024)
)
```

| 変数 | 形状 | 意味 |
|------|------|------|
| `x_sim` | `(100000, 4)` | 正規化剛性パラメータ $\theta \in [0,1]^4$ |
| `y_sim` | `(100000, 4, 1, 1024)` | クリーンFRF（4階分、1024点） |
| `y_sim_n` | `(100000, 4, 1, 1024)` | ノイズ付きFRF（訓練入力として使用） |

**形状 `(100000, 4, 1, 1024)` の読み方：**

```
サンプル数 × チャンネル × 高さ × 幅
100000     × 4（各階） × 1    × 1024（周波数点数）
```

「高さ=1」は1次元FRFデータを Conv2d で処理するための擬似的な2次元化（[03_ml_prerequisites.md §4.4](03_ml_prerequisites.md) 参照）。

### 6.4 訓練での使い方

MVAE の訓練では、データセットから次のペアを取り出す：

```python
# train.py（概念的な説明）
y_n = y_sim_n[:, [-1], :, :]   # ノイズあり屋根FRF → エンコーダ enc_x の入力（xo）
y   = y_sim  [:, [-1], :, :]   # クリーン屋根FRF   → エンコーダ enc_x の入力（xi）
w   = x_sim                     # 正規化パラメータ  → エンコーダ enc_w の入力
```

`model.loss(xo=y_n, xi=y, w=w)` を計算し、FRFとパラメータが同じ潜在空間に埋め込まれるよう学習する。

```
│  x_obs を enc_x で潜在空間に埋め込み（一度だけ）                     │
│       ↓                                                             │
│  SMC ループ（β: 0 → 1 のテンパリング）:                             │
│    粒子 θ を enc_w で潜在空間に埋め込み                              │
│    潜在空間上でガウス尤度を計算（解析的・高速）                       │
│    重み更新 → リサンプリング → RW-MH カーネルで粒子を動かす          │
│       ↓                                                             │
│  事後分布サンプル（2000粒子）を posterior.mat に保存                  │
└─────────────────────────────────────────────────────────────────────┘
```

### 各ステップの計算コストのイメージ

| ステップ | 計算量 | 支配的な処理 |
|---------|-------|------------|
| Step 1 | 大（数時間）| 100,000回のFRF計算（並列化で短縮） |
| Step 2 | 中（数十分〜数時間）| GPU上でのMVAE訓練 |
| Step 3 | 小（数分）| 潜在空間上の軽い計算（FRF計算なし） |

Step 3 が軽いのは、「FRF計算（重い）」をStep 2 で学習した MVAE（軽い）に置き換えているため。これが本手法の最大のメリット。

## 8. 本研究の新規性と位置づけ

### 8.1 従来手法の課題

| 手法 | 問題点 |
|------|--------|
| 最適化ベース | 多峰性に対応できず一つの解しか見つからない |
| MCMC（HMC・NUTS）| 多峰性に弱い。FRFの高次元（1024次元）で尤度計算が不安定 |
| ニューラルネットワーク直接推定 | 点推定になりがち。不確実性を定量化できない |

### 8.2 本手法（LSBI-SMC）のアプローチ

1. **次元削減（MVAE）：** 1024次元のFRFを8次元の潜在空間に圧縮。高次元問題を回避
2. **解析的な尤度計算：** 潜在空間でガウス分布の積の公式を使い、積分を閉形式で計算
3. **多峰性対応（SMC）：** テンパリングで事後分布のすべての峰を捉える
4. **不確実性の定量化：** 点推定でなく分布（2000個の粒子）として推定結果を提供

```
【入力】屋根のFRF（1024次元）

  1. enc_x で潜在空間に写像（8次元）
         ↓
  2. SMCで事後分布を推定（潜在空間上で計算）
         ↓ 各粒子（候補θ）に対して：
         └─ enc_w でθを潜在空間に写像（8次元）
         └─ 潜在空間上でガウス尤度を計算（解析的・一瞬）
         ↓
【出力】θ = (k₁, k₂, k₃, k₄) の事後分布（2000サンプル）
        → 「真値はここらへんにある（± 不確実性）」という推定結果
```
