# 研究背景 — 工学逆問題と不確実性

**工学では「観測から内部パラメータを推定」する逆問題が遍在**

- 構造物の剛性・減衰の同定（地震応答予測のため）
- 材料定数・損傷度の推定
- 流体・熱輸送パラメータの推定

**点推定では不十分** — リスク評価・診断・意思決定には推定の **不確実性定量化** が必須

**ベイズ推論**は事後分布として不確実性を直接与える:

$$
p(\theta \mid x_\mathrm{obs}) \;\propto\; \underbrace{L(\theta;\,x_\mathrm{obs})}_{\text{尤度}} \cdot \underbrace{p(\theta)}_{\text{事前}}
$$

# 既存アプローチと残された課題

**ベイズ推論の実現方式**（参照: papers/previous/）:

| 方式                         | 代表                                    | 強み           | 弱み                  |
| ---------------------------- | --------------------------------------- | -------------- | --------------------- |
| 古典 MCMC + 解析尤度         | Beck & Katafygiotis (1998)              | 厳密           | 高次元・高コストで非実用 |
| Normalizing Flow             | Zeng et al. (2025)                      | 表現力         | 学習重い              |
| 拡散モデル                   | Wang & Bi (2026)                        | 多モード対応   | 推論遅い              |
| **潜在空間ベイズ (LSBI)**    | Itoi (2024), Yaoyama (2026)             | **閉形式尤度・高速** | 表現力に制限      |

**残された課題**:
1. 各手法の**問題ごとの優劣が未整理** — 横断的な比較がほぼない
2. 既存実装は **特定構成 (MVAE+SMC等) に固定** — 差し替えが困難
3. **工学一般への適用性** のエビデンスが限定的（特定の構造問題に偏り）

# 本研究のスタンス — 比較可能なフレームワーク

「**どの手法がどの問題に良いか**」は問題依存 — 事前には決められない

→ **各構成要素を差し替えて試せる共通基盤**が必要

**研究目的**:

- 工学逆問題に対する **不確実性定量化付き推定** を、
- **手法を差し替えて比較できる** 形でフレームワーク化

**戦略**:
- まず**潜在空間ベイズ (LSBI-SMC, Yaoyama 2026)** を起点として実装
- そこから尤度モデル・サンプラー・カーネル等を **Protocol で抽象化**
- 後続で他手法（NF / 拡散 / 直接尤度 / HMC / NUTS …）を **差し替え可能** に

> 本発表は「**この基盤を最初の手法で動かすところまで**」を扱う。

# 自分が取り組んだこと① — 論文理解とアルゴリズム整理

**ベース論文 Yaoyama et al. (2026)** をコードレベルで読み解き、各構成要素の役割を整理:

| 構成要素        | 役割                                                        |
| --------------- | ----------------------------------------------------------- |
| MVAE            | 2 つのエンコーダで $\theta$ と $x$ を共通潜在空間に投影     |
| 潜在尤度        | $\int q_{\phi_x}\,q_{\phi_\theta}\,/\,p(z)\,dz$ を閉形式評価 |
| SMC             | 焼きなまし + リサンプリング + MCMC、ESS 適応                |
| MCMC カーネル   | RW-Metropolis、Ching & Chen の適応共分散                    |
| 事前分布        | $\theta_i \sim$ 一様 (物理的範囲)                           |

各要素の **数値安定化** や **GPU 並列化** の実装上の工夫も併せて整理。

# 自分が取り組んだこと② — ライブラリ設計と再実装

**設計思想**: 「どの手法がどの問題に効くか」を **手軽に試せる** 基盤を作る

各構成要素を Python **`Protocol`** で抽象化し、後から差し替え可能に:

| モジュール     | 現在の実装              | 抽象化 Protocol                          |
| -------------- | ----------------------- | ---------------------------------------- |
| サンプラー     | SMC                     | `class SMC` → HMC/NUTS/NS 差し替え可     |
| MCMC カーネル  | RW-Metropolis           | `KernelProtocol` → MALA/HMC              |
| 提案分布       | Ching & Chen (2007)     | `ProposalProtocol` → 適応 MH 等          |
| 尤度モデル     | MVAE 潜在尤度           | `LikelihoodProtocol` → **NF/拡散/直接尤度** |
| 事前分布       | HierarchicalPrior (DAG) | `PriorProtocol` → 任意の確率変数         |

**その他の改善**: モジュール依存関係の整理 / `uv` 管理 + パッケージ公開 / ドキュメント整備

> MVAE は出発点であって終着点ではない — **比較研究の土台**

# 検証例 — 4自由度せん断建物

**設定** (Yaoyama 2026 と同じ):

- 4 層モデル、各層は **水平 1 方向のみ変位**、$k_i = \theta_i k$, $\theta_i \in [0.33, 3.00]$
- Rayleigh 減衰、観測は **屋上 FRF のみ** (1024 点 + ノイズ)
- 真値 $\theta = (1,1,1,1)$、事前は一様

**運動方程式**:

$$
M\ddot{\mathbf{u}} + C\dot{\mathbf{u}} + K(\theta)\mathbf{u} = -M\boldsymbol{\iota}\ddot{u}_g
\qquad (\mathbf{u}\in\mathbb{R}^4)
$$

**狙い**: 多峰性のある古典的なベンチマークでフレームワークの動作確認

# 現状の限界と今後 — まずは尤度モデルの拡張比較から

**現状の限界**:
- 検証は **4DOF せん断建物のみ** — 工学一般への適用性は未確認
- 比較対象がまだない: 他の尤度モデル・サンプラーは未実装
- **「結局どの手法がベストか」にはまだ答えられない**

**今後 (焦点を絞る)**:

🎯 **まず尤度モデル部分の拡張・比較**
- 標準 VAE / **Normalizing Flow** / **拡散モデル** / 直接尤度 を実装
- 同一ベンチマーク上で **横断比較**（精度・時間・多峰性への頑健さ）

→ 次のステップ: より複雑な系（高次元・非線形・多モダリティ観測）への適用拡大
→ 究極目標: 「**工学逆問題ごとに最適な手法構成を選べる**」ライブラリへ
