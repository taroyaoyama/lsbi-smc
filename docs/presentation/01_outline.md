### Slide 1: 研究背景 — なぜFEモデル更新が必要か
**言いたいこと**: 設計時のFEMと実建物には乖離があり、地震応答予測のためには観測データに基づくモデル較正が必要。

- 建物の地震応答予測 → 高精度なFEモデルが前提
- しかし設計FEMは実建物の剛性・減衰と必ずしも一致しない
  - 経年劣化、施工誤差、非構造部材の寄与 …
- **モデル更新 (FE model updating)**: 観測振動 → パラメータ θ（剛性等）を逆推定
- 決定論的 fitting では不十分 → **確率論的 (ベイズ的) 推定**で不確かさを定量化したい

**図**: 建物の写真 or 模式図 + FEMモデル + 「θ = ?」

---

### Slide 2: 目的・課題
**言いたいこと**: ベイズ的FE updating は理想的だが、3つの壁がある。

目的: 観測FRF $x_\mathrm{obs}$ から、剛性パラメータ $\theta$ の **事後分布** $p(\theta \mid x_\mathrm{obs})$ を効率的に推定する

3つの課題:
1. **高次元観測**: FRF は 1024点 → 尤度 $p(x_\mathrm{obs} \mid \theta)$ の直接定義が難しい
2. **シミュレータ高コスト**: 通常MCMCは数十万回FE解析を呼ぶ → 非現実的
3. **多峰性**: 同じ屋根応答を再現するθの組み合わせが複数（等価解）

**図**: 3つの課題をアイコン化

---

### Slide 3: 提案手法（既存） — 全体像
**言いたいこと**: オフライン学習 + オンライン推論の2段構え。

```
[オフライン]                          [オンライン]
事前分布 ─→ FE解析 ─→ (θ, FRF) ─→ MVAE学習 ─→ ┐
                                                   │
                            観測 x_obs ──────────→ SMC ─→ 事後分布 p(θ|x_obs)
```

3ステップ:
1. データセット生成（FE並列実行）
2. **MVAE学習** — θ と FRF を共通の潜在空間 $z$ に写す
3. **SMC推論** — 潜在空間で尤度を計算してサンプリング

**図**: 既存 docs/00_overview.md のパイプライン図を整形して図化（オフライン/オンライン色分け）

---

### Slide 4: Step 2 — MVAE (Multimodal VAE) で潜在空間を作る
**言いたいこと**: 「θ も FRF も、同じ潜在変数 z から生成される」ように2つのエンコーダを揃える。

- 構造: パラメータ用エンコーダ $\mathrm{enc}_w(\theta)$、FRF用エンコーダ $\mathrm{enc}_x(x)$、共通デコーダ $\mathrm{dec}(z)$
- 損失: 再構成項 + **2方向KL** $\mathrm{KL}(q_w \,\|\, q_x) + \mathrm{KL}(q_x \,\|\, q_w)$
  - → 2つのエンコーダが同じ z 表現を返すよう揃う
- 効果: 学習後、$\theta$ も $x$ も同じ低次元 ($z\in\mathbb{R}^{d}$) で比較可能に

**図**: 2エンコーダ + 1デコーダ + 潜在空間の簡略ネットワーク図（docs/05_mvae.md を整形）

**ML弱め向け補足**: VAEは「データを低次元の潜在変数に圧縮し、そこから復元できるよう学習する手法」と1文だけ説明

---

### Slide 5: Step 3a — 潜在空間ベース尤度
**言いたいこと**: 1024次元のFRFを直接比較せず、低次元の潜在空間で尤度を評価する。これによりSMCのMCMCループでFE解析を呼ばなくて済む。

- 観測 $x_\mathrm{obs}$ を1度だけ $\mathrm{enc}_x$ で潜在化 → $(\mu_\mathrm{obs}, \sigma^2_\mathrm{obs})$
- 候補 $\theta$ を $\mathrm{enc}_w$ で潜在化 → $(\mu_w, \sigma^2_w)$
- 両者をガウスとみなして潜在事前 $\mathcal{N}(0,I)$ 上で解析的に積分
- **対数尤度が閉形式で計算可能** → FEシミュレータ呼び出し不要

数式（簡略版・1行）:
$$\log p(x_\mathrm{obs} \mid \theta) \approx \log \int \mathcal{N}(z; \mu_\mathrm{obs}, \sigma^2_\mathrm{obs})\, \mathcal{N}(z; \mu_w, \sigma^2_w)\, \mathcal{N}(z; 0, I)\, dz$$

**図**: 「FRF空間で比較する」vs「潜在空間で比較する」概念図（2パネル比較）

---

### Slide 6: Step 3b — SMC（逐次モンテカルロ）
**言いたいこと**: 事前分布から事後分布まで温度を段階的に上げることで、多峰性に強く・並列化可能なサンプリングを実現。

- 逆温度 $q$ を $0$（事前）→ $1$（事後）に焼きなまし
- 各段階で: ① 重みづけ → ② リサンプリング → ③ MCMC kernel (RW-Metropolis) で多様化
- $q$ の刻み幅は **ESS（実効サンプル数）** に基づき適応的に決定（binary search）
- 粒子は独立に進化 → **並列化が自然**

**図**: 事前 → 中間 → 事後 への粒子群の遷移イメージ（3パネル散布図）

---

### Slide 7: ベンチマーク — 4自由度せん断建物
**言いたいこと**: 論文と同一の検証問題で実装が正しく動くことを確認。

- モデル: 4層せん断モデル、各層に剛性 $k_i \in [0.33, 3.00]$（正規化）
- 観測: 屋根のFRF（1024点、ホワイトノイズ励振、付加ノイズあり）
- 真値: $(k_1, k_2, k_3, k_4) = (1.0, 1.0, 1.0, 1.0)$
- 訓練データ: 事前から $N$ サンプル → FE並列実行で生成
- SMC設定: 粒子数、MCMC step数 など

### Slide 9: 本研究の貢献 — 現実装を拡張しやすい形で再実装
**言いたいこと**: 手法そのものは既存論文。本研究は、その実装を**現方式のまま**、各構成要素を後から差し替えられる形に再整理したもの。代替手法そのものは未実装で、それらを足していくための基盤を作った段階。

- 既存論文公開コード → 一枚岩で、他手法を試すには大幅な書き換えが必要
- 本研究では **モジュール境界を切った Python パッケージ**として再実装（実装している中身は論文と同じ手法のみ）
- 各モジュールは差し替え可能なインターフェースを持つ:

| モジュール | 現在実装している中身 | 設計上の拡張余地（未実装） |
|---|---|---|
| サンプラー | SMC | HMC, NUTS, Nested Sampling などへ差し替え可能 |
| MCMCカーネル | RW-Metropolis | MALA, HMC などへ差し替え可能 |
| 提案分布 | Ching & Chen (2007) | 適応的MH, 学習ベース提案 などへ差し替え可能 |
| 尤度モデル | MVAE 潜在尤度 | 標準VAE, Normalizing Flow, 直接尤度 などへ差し替え可能 |
| 事前分布 | HierarchicalPrior (DAG) | 任意の確率変数の組み合わせを宣言的に書ける |

- 主な再実装上の整備点（例 — 後で具体化）:
  - 数値安定化（log-weights クリップ、共分散正則化 など）
  - シミュレータの並列化整理 / 学習パイプラインの分離
  - 事前分布をDAGで宣言的に書ける仕組み
- 位置づけ: **今後の手法比較研究のための土台**。比較実験そのものは今後の展望（Slide 10）に続く

**図**: モジュールブロック図（実装済み = 塗り、拡張余地 = 点線枠 など、視覚的に区別）
